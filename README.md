# Hiver AI Support Agent

AI customer-support agent built for the Hiver SDE Intern take-home assignment.

## Goal

The system will:

1. Classify incoming customer messages into brand-specific intents.
2. Draft replies grounded in historical support conversations.
3. Decide whether a message should be auto-handled or escalated.
4. Evaluate the system using a hand-labelled golden evaluation set.
